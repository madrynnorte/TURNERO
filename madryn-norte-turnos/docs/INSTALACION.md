# Instalación en iPhone, Android y PC

La aplicación es una PWA: se abre desde una URL segura y puede instalarse sin App Store ni Play Store. Para instalarla se necesita primero una URL publicada con HTTPS.

## iPhone o iPad

1. Abrir la URL en Safari.
2. Tocar **Compartir**.
3. Elegir **Agregar a inicio**.
4. Confirmar con **Agregar**.
5. Abrir el ícono “Madryn Norte” desde la pantalla de inicio.

Si la opción no aparece, verificar que se esté usando Safari y no el navegador interno de WhatsApp, Instagram o Gmail.

## Android

1. Abrir la URL en Chrome.
2. Tocar el menú de tres puntos.
3. Elegir **Instalar aplicación** o **Agregar a la pantalla principal**.
4. Confirmar la instalación.

Chrome también puede mostrar un botón **Instalar** en la barra de direcciones.

## PC con Windows, macOS o Linux

1. Abrir la URL en Chrome o Microsoft Edge.
2. Hacer clic en el ícono de instalación de la barra de direcciones.
3. Confirmar **Instalar**.
4. Opcionalmente, fijar la aplicación a la barra de tareas o al menú Inicio.

También funciona sin instalar: basta con abrir la URL en un navegador moderno.

## Uso local en una PC administradora

Para una prueba sin publicación, iniciar el servidor siguiendo el README y abrir `http://127.0.0.1:8787` en esa misma PC. Esa dirección no sirve para otros teléfonos salvo que se configure la red local y el firewall; para uso real se recomienda la URL HTTPS publicada.

## Primer ingreso

Ingresar con una de las cuentas iniciales documentadas en el README. La cuenta `consulta` no puede alterar datos. Cambiar las claves iniciales antes de abrir el acceso a Internet.
